# Interactive JavaScript Quiz App 🧠

A responsive and interactive quiz application built with vanilla JavaScript, HTML, and CSS. This project tests a user's knowledge with multiple-choice questions, provides instant feedback, and displays a final score upon completion.

**➡️ [View Live Demo](https://webquiz-game.netlify.app/)**

## ✨ Features

* **Dynamic Q&A:** Questions and answers are loaded dynamically from a JavaScript array, making it easy to add or change quiz content.
* **Multi-Screen Interface:** A clean user experience with separate screens for the start menu, the quiz itself, and the final results.
* **Instant Feedback:** When an answer is selected, buttons are immediately highlighted as correct or incorrect, helping users learn as they go.
* **Real-time Progress:** A progress bar and question counter (`X / Y`) keep the user informed of their progress through the quiz.
* **Score Tracking:** The score updates in real-time as the user answers questions correctly.
* **Personalized Results:** The final results screen shows the total score and a custom message based on the user's performance.
* **Restart Functionality:** Users can easily restart the quiz from the results screen to try and beat their high score.

---

## 🛠️ Tech Stack

* **HTML5:** For the basic structure and content of the quiz.
* **CSS3:** For styling the application, including screen transitions and feedback animations.
* **Vanilla JavaScript:** For all the core logic, including DOM manipulation, event handling, and state management. No external libraries or frameworks were used.
